# RoyCSS Test Suite

Vitest unit tests + Playwright E2E tests for the RoyCSS effects library and
marketing site. Established from scratch by the Quality Engineering agent.

## Layout

```
tests/
├── unit/                          # Vitest — pure-TS, no DOM
│   ├── effects.test.ts            # 1,569-effect corpus invariants
│   ├── categories.test.ts         # 20-category taxonomy
│   ├── recipes.test.ts            # 12 recipes + searchRecipes()
│   ├── patterns.test.ts           # 10 patterns + searchPatterns()
│   ├── design-tokens.test.ts      # OKLCH-only / color-mix / generators
│   └── framework-adapters.test.ts # 6 framework code examples
├── e2e/                           # Playwright — chromium vs. dev server
│   ├── home.spec.ts
│   ├── effects-grid.spec.ts
│   ├── search-overlay.spec.ts
│   ├── recipes.spec.ts
│   ├── patterns.spec.ts
│   ├── playground.spec.ts
│   ├── navigation.spec.ts
│   ├── theme-toggle.spec.ts
│   ├── contact-form.spec.ts
│   └── footer.spec.ts
├── coverage/                      # generated by vitest (gitignored)
└── REPORT.md                      # latest pass/fail + coverage snapshot
```

Configs live at the repo root: `/vitest.config.ts`, `/playwright.config.ts`.

## Prerequisites

The test dependencies are already in `package.json` `devDependencies`:

- `vitest` 4.x
- `@vitest/coverage-v8` 4.x
- `@playwright/test` 1.62+
- `bun-types`, `typescript` (already present)

If you're bootstrapping a fresh checkout, install everything with:

```bash
bun install
bunx playwright install chromium        # ~115 MB, one-time
```

## Running unit tests

```bash
# Single run with coverage report
bunx vitest run --coverage

# Watch mode (no coverage)
bunx vitest

# Run a single file
bunx vitest run tests/unit/effects.test.ts

# Coverage HTML report opens at tests/coverage/index.html
```

**Coverage gate:** `vitest.config.ts` enforces ≥ 70 % lines / functions /
branches / statements on `src/lib/**`. A run that drops below fails CI.

## Running E2E tests

The Playwright config auto-starts `bun run dev` on port 3000 the first time
you run `bunx playwright test`. If you already have a dev server running
locally, set `PLAYWRIGHT_NO_SERVER=1` to skip the auto-start.

```bash
# Full chromium suite (auto-starts dev server)
bunx playwright test

# Single spec file
bunx playwright test tests/e2e/home.spec.ts

# Headed mode (visible browser)
bunx playwright test --headed

# Step-through debugger
bunx playwright test --debug

# View the HTML report from the last run
bunx playwright show-report

# Point at an already-running server
PLAYWRIGHT_NO_SERVER=1 bunx playwright test

# Point at a different URL (e.g. preview deploy)
PLAYWRIGHT_BASE_URL=https://roycss-preview.example.com bunx playwright test
```

**Retry policy:** 1 retry on CI (`CI=true`), 0 retries locally.

## Running both

```bash
bunx vitest run --coverage && bunx playwright test
```

## CI integration (sketch)

```yaml
# .github/workflows/quality.yml
jobs:
  unit:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v2
      - run: bun install --frozen-lockfile
      - run: bunx vitest run --coverage
      - uses: actions/upload-artifact@v4
        with: { name: coverage, path: tests/coverage }
  e2e:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v2
      - run: bun install --frozen-lockfile
      - run: bunx playwright install --with-deps chromium
      - run: bunx playwright test
        env: { CI: "true" }
      - uses: actions/upload-artifact@v4
        if: failure()
        with: { name: playwright-trace, path: test-results }
```

## Troubleshooting

| Symptom                                              | Fix                                                                 |
| ---------------------------------------------------- | ------------------------------------------------------------------- |
| `bunx vitest` errors with "Cannot find module '@/'`  | The path alias is configured in `vitest.config.ts`; run from repo root. |
| Playwright: "webServer timeout"                      | Increase `webServer.timeout` in `playwright.config.ts`; or run `bun run dev` manually and use `PLAYWRIGHT_NO_SERVER=1`. |
| Coverage < 70 % after adding a new `src/lib/` module | Add unit tests for the new module; if it's pure data (like `effects-batch-*.ts`), add it to `coverage.exclude` only if it's covered transitively. |
| `bunx playwright test` reports "chromium not found"  | Run `bunx playwright install chromium`.                             |
| Contact-form spec fails on submit                    | Confirm `page.route("**/api/contact", …)` mock is still wired; the API contract may have changed. |
