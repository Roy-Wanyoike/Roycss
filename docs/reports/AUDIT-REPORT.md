## 11. What's left (intentionally minimal)

All backend modules have real implementations. The remaining gaps are:

1. **LLM API key** — `OPENAI_API_KEY` or `ANTHROPIC_API_KEY` env var. Currently uses mock LLM responses. Set the env var to enable real LLM calls.
2. **External service API tokens** — `CDN_API_TOKEN`, `STORAGE_*`, `FIGMA_TOKEN`, `GITHUB_TOKEN`, `NPM_TOKEN`. Currently fall back to mock implementations. Set the env vars to enable real API calls.
3. **Production Postgres swap** — Need Supabase direct Postgres access (port 5432) OR pooler URL with correct region. Currently using SQLite locally.
4. **Email service** — `RESEND_API_KEY` for transactional emails from contact form. Currently the contact form persists to DB but doesn't send email.
5. **Sentry observability** — `SENTRY_DSN` for error tracking. Not currently configured.
