     1→# RoyCSS Documentation Site — Architecture & Design
     2→
     3→> **Mission:** Build the best CSS-effects documentation site ever shipped — surpassing Tailwind CSS, Animate.css, and Bootstrap docs in depth, interactivity, accessibility, and developer productivity. RoyCSS ships **700+ production-ready effects** across 20 categories; the docs must make every one of them discoverable, understandable, copyable, and verifiable in under 30 seconds.

    24→## 1. Goals
    25→
    26→### 1.1 Primary Goals
    27→
    28→| # | Goal | Success Metric |
    29→|---|------|----------------|
    30→| G1 | **Every effect discoverable in <30s** | Median time-to-effect ≤ 30s from landing |
    31→| G2 | **Every effect usable without reading prose** | Live preview + copyable code on every page |
    32→| G3 | **Best-in-class search** | Cmd+K → typed query → preview rendered ≤ 120ms p95 |
    33→| G4 | **Zero-accessibility surprises** | WCAG 2.1 AA + reduced-motion notes on every effect |
    34→| G5 | **Framework-agnostic onboarding** | React, Vue, Angular, Svelte, vanilla HTML tabs per page |
    35→| G6 | **Performance transparency** | Bundle size + render cost shown for every effect |
    36→| G7 | **AI-native authoring** | Prompt → working snippet in ≤ 5s |
    37→| G8 | **Sub-1s TTI globally** | Lighthouse ≥ 98 on every docs route |
    38→
    39→### 1.2 Design Principles
    40→
    41→1. **Show, don't tell.** Every concept opens with a live preview. Prose comes second.
    42→2. **Copy-first.** Every code block has Copy HTML, Copy CSS, Copy JSX, Copy URL actions.
    43→3. **Progressive disclosure.** Default view = preview + class name. Expand for accessibility, performance, variants, source.
    44→4. **Keyboard complete.** The entire site is operable from the keyboard, with documented shortcuts.
    45→5. **Theme honest.** Light, dark, and system themes are first-class — every preview validates in all three.
    46→6. **Versioned truth.** Every page is pinned to a version; switching versions re-renders content.
    47→7. **AI as collaborator.** AI is not a chatbot bolted on; it's woven into search, snippets, and migration.
    48→
    49→### 1.3 Non-Goals
    50→
    51→- We are not building a CMS. Content lives in Markdown + TypeScript data files in the repo.
    52→- We are not building a community forum. Discussions link to GitHub Discussions.
    53→- We are not building a CDN playground. Sandboxes embed StackBlitz / CodeSandbox iframes.

   103→### 2.2 Effect Taxonomy
   104→
   105→Each of the 700+ effects carries this metadata (sourced from `src/lib/roycss-types.ts`):
   106→
   107→```typescript
   108→interface EffectDoc extends CSSEffect {
   109→  slug: string;                    // URL-safe identifier
   110→  versionAdded: string;            // e.g. "1.0.0"
   111→  versionDeprecated?: string;
   112→  replacementFor?: string[];       // renamed effects
   113→  bundleBytes: number;             // gzipped CSS bytes
   114→  renderCost: "low" | "medium" | "high";  // compositor / layout / paint
   115→  triggersLayout: boolean;
   116→  triggersPaint: boolean;
   117→  triggersCompositor: boolean;
   118→  accessibility: {
   119→    motionSafe: boolean;           // honors prefers-reduced-motion
   120→    contrastSafe: boolean;         // WCAG AA on default surfaces
   121→    flashSafe: boolean;            // no >3Hz flashing
   122→    screenReaderNeutral: boolean;  // decorative-only
   123→  };
   124→  variants: string[];              // e.g. ["-soft", "-strong", "-slow"]
   125→  frameworkSnippets: {
   126→    html: string;
   127→    react: string;
   128→    vue: string;
   129→    svelte: string;
   130→    angular: string;
   131→  };
   132→  relatedEffects: string[];        // slugs
   133→  realWorldUsage: string[];        // e.g. ["loading state", "hero CTA"]
   134→  aiPromptHints: string[];         // surfaces in AI search
   135→}
   136→```
   137→
   138→### 2.3 URL Scheme
   139→
   140→```
   141→/docs/effects/[category]/[effect-slug]           ← single effect
   142→/docs/effects/[category]                          ← category index
   143→/docs/explorer/components                         ← visual browser
   144→/docs/explorer/utilities                          ← class-name browser
   145→/docs/api/[type]/[name]                           ← API reference
   146→/docs/migration/[from]-to-roycss                  ← migration guide
   147→/docs/[version]/...                               ← versioned snapshot
   148→```
   149→
   150→Canonical URLs always point to the latest stable; `?v=1.2.0` or `/v1.2.0/` pins a version.

   332→## 4. Search System
   333→
   334→### 4.1 Goals
   335→
   336→- **Instant (<120ms p95)** — results appear as the user types, before they finish.
   337→- **Fuzzy** — `plsGlow` matches `pulse-glow`; `hdrglow` matches `hover-glow-border`.
   338→- **Multi-modal** — searches effects, utilities, API symbols, docs pages, and AI prompts.
   339→- **Keyboard-native** — `Cmd+K` opens, arrow keys navigate, `Enter` jumps, `Esc` closes.
   340→- **Previewable** — hovering a result shows a live mini-preview, not just text.
   341→
   342→### 4.2 Architecture
   343→
   344→```
   345→┌────────────────────────────────────────────────────────────┐
   346→│  Build Time (Node script in /scripts/build-search-index.ts) │
   347→│                                                            │
   348→│  effects.json + docs/*.md + api/*.ts                       │
   349→│        │                                                   │
   350→│        ▼                                                   │
   351→│  ┌──────────────┐    ┌────────────────┐                    │
   352→│  │ MiniSearch   │    │ Embeddings     │                    │
   353→│  │ (lexical,    │    │ (vector, 384d, │                    │
   354→│  │  fuzzy, BM25)│    │  MiniLM)       │                    │
   355→│  └──────────────┘    └────────────────┘                    │
   356→│        │                     │                             │
   357→│        ▼                     ▼                             │
   358→│  search-index.json     embeddings.bin (binary, ~2MB)       │
   359→│        │                     │                             │
   360→│        └──────────┬──────────┘                             │
   361→│                   ▼                                        │
   362→│          Static export to /public/search/                  │
   363→└────────────────────────────────────────────────────────────┘
   364→                            │
   365→                            ▼  (loaded once, cached)
   366→┌────────────────────────────────────────────────────────────┐
   367→│  Runtime (in-browser)                                      │
   368→│                                                            │
   369→│  User query → ┌─────────────┐  ┌──────────────────────┐    │
   370→│               │ MiniSearch  │  │ Vector similarity    │    │
   371→│               │ (lexical)   │  │ (cosine, top-50)     │    │
   372→│               └──────┬──────┘  └──────────┬───────────┘    │
   373→│                      └──────┬─────────────┘                │
   374→│                             ▼                              │
   375→│                    Reciprocal Rank Fusion                  │
   376→│                             │                              │
   377→│                             ▼                              │
   378→│               Ranked results + AI prompt path              │
   379→└────────────────────────────────────────────────────────────┘
   380→```

   415→
   416→**UX rules:**
   417→
   418→- Modal opens in 1 frame (`opacity` transition only, no transform).
   419→- First result is auto-selected; `Enter` opens it.
   420→- `Tab` cycles sections (Effects → AI → Docs → API).
   421→- `Cmd+Enter` opens the selection in a new tab.
   422→- `Cmd+C` while a class is selected copies the class name (no need to open the page).
   423→- Recent searches persist in `localStorage` (last 8, deduped).
   424→- AI prompt path: if the query reads like intent ("add a glow to my button"), surface the AI suggestion above lexical results.
   425→
   426→### 4.4 Ranking Signals
   427→
   428→Each result score combines:
   429→
   430→| Signal | Weight | Notes |
   431→|--------|--------|-------|
   432→| Lexical BM25 (MiniSearch) | 0.35 | exact + fuzzy |
   433→| Vector similarity | 0.30 | semantic match |
   434→| Tag match | 0.10 | `tags[]` field |
   435→| Popularity (copy count) | 0.10 | global usage signal |
   436→| Recency boost | 0.05 | new in last 2 versions |
   437→| Page-rank (internal links) | 0.05 | docs graph centrality |
   438→| Exact-class match | 0.05 | `roycss-pulse-glow` exact |

   450→│  Files: [index.html ▾] [style.css] [script.js]    [Run ▶] │
   451→├────────────────────────────────┬───────────────────────────┤
   452→│  <div class="roycss-pulse-     │                           │
   453→│    glow">                      │                           │
   454→│    Hover or focus me           │      [LIVE PREVIEW]       │
   455→│  </div>                        │                           │
   456→│                                │      ▶ pulse-glow         │
   457→│  <style>                       │                           │
   458→│    @import "roycss";           │                           │
   459→│    :root {                     │                           │
   460→│      --roy-color-primary:      │                           │
   461→│        oklch(0.7 0.14 165);    │                           │
   462→│    }                           │                           │

   468→

   470→- **Auto-run** with 300ms debounce — preview re-renders on every keystroke.
   471→- **Share URL** encodes the entire sketch in a compressed query string (LZ-string + base64).
   472→- **Permalink** to any state — useful for bug reports and Discord help.
   473→- **No backend** — runs entirely in the browser; CDN serves the `roycss` package.
   474→
   475→### 5.2 Code Generation
   476→
   477→Beyond copy-paste, the site generates framework-specific code:
   478→
   479→- **HTML** — semantic markup with the class applied.
   480→- **React** — `className="roycss-pulse-glow"` with TypeScript props.
   481→- **Vue** — `<template>` + scoped `<style>` import.
   482→- **Svelte** — `<div class="roycss-pulse-glow">` with `import "roycss/css"`.

   484→- **Astro** — Astro-flavored snippet.
   485→- **Plain CSS** — just the `@keyframes` + selector for self-contained copy.
   486→
   487→The generator is a pure function of `(effect, framework, options)` so the same input always produces identical output (deterministic snapshots for tests).

   601→## 7. AI Integration
   602→
   603→### 7.1 Philosophy
   604→
   605→AI is a **first-class authoring surface**, not a chatbot sidebar. Three integration points:
   606→
   607→1. **Search** — intent detection routes natural-language queries to a generation path.
   608→2. **Snippet generation** — users ask for an outcome; the site returns working code.
   609→3. **Migration** — paste Animate.css / Tailwind code, get RoyCSS equivalent.
   610→
   611→### 7.2 Prompt Examples (Built-In Library)
   612→
   613→The AI Playground ships with 40+ curated prompts, each linked to real effects:
   614→
   615→| Prompt | Generated Output |

   617→| "Generate a hero section with glow effect" | `<section>` + `roycss-anim-pulse-glow` + gradient overlay |
   618→| "Make my button shake on error" | `roycss-anim-shake` + error-state CSS |
   619→| "Add a loader to my async card" | `roycss-load-spinner` + skeleton fallback |
   620→| "Underline my nav links on hover with a slide" | `roycss-hover-underline-slide` applied to `<a>` |
   621→| "Glassmorphism sidebar" | `roycss-glass-frosted` + `backdrop-filter` note |
   622→| "3D tilt card on hover" | `roycss-transform-3d-tilt` + perspective container |
   623→| "Animate counter from 0 to 1000" | `roycss-anim-count-up` + JS hook |
   624→| "Page transition fade between routes" | `roycss-page-fade` + framework router snippet |

   626→### 7.3 Generation Pipeline
   627→
   628→```

   630→     │
   631→     ▼
   632→[1] Intent classification
   633→    (hero | loader | hover | transition | microinteraction | error | success)

   635→     ▼

   638→     │
   639→     ▼

   643→     ▼

   715→
   716→### 8.1 From Animate.css
   717→
   718→A side-by-side mapping table for all 75 Animate.css classes:
   719→
   720→| Animate.css | RoyCSS | Notes |
   721→|-------------|--------|-------|
   722→| `animate__bounce` | `roycss-anim-bounce-in` | entrance direction differs; see docs |
   723→| `animate__flash` | `roycss-anim-flash` | 1:1 |
   724→| `animate__pulse` | `roycss-anim-pulse-soft` | softer by default |
   725→| `animate__rubberBand` | `roycss-anim-rubber-band` | 1:1 |
   726→| `animate__shake` | `roycss-anim-shake` | 1:1 |
   727→| `animate__swing` | `roycss-anim-swing` | 1:1 |
   728→| `animate__tada` | `roycss-anim-tada` | 1:1 |
   729→| `animate__wobble` | `roycss-anim-wobble` | 1:1 |
   730→| `animate__fadeIn` | `roycss-anim-fade-in` | 1:1 |
   731→| `animate__fadeInUp` | `roycss-anim-fade-in-up` | 1:1 |
   732→| `animate__zoomIn` | `roycss-anim-zoom-in` | 1:1 |
   733→| `animate__slideInLeft` | `roycss-anim-slide-in-left` | 1:1 |
   734→| `animate__flipInX` | `roycss-anim-flip-in-x` | 1:1 |
   735→| ... | ... | full table on the migration page |
   736→
   737→The migration page also includes:
   738→
   739→- **Drop-in replacement CSS** — a compatibility layer that maps Animate.css class names to RoyCSS effects for incremental migration.
   740→- **Codemod** — `npx roycss migrate animate-css ./src` rewrites class names in place.
   741→- **Behavioral differences** — e.g. RoyCSS's `bounce-in` includes a subtle shadow drop Animate.css doesn't.
   742→
   743→### 8.2 From Tailwind CSS
   744→
   745→Tailwind doesn't ship animations beyond `animate-spin/ping/pulse/bounce`. The migration guide:
   746→
   747→1. **Coexistence** — RoyCSS sits alongside Tailwind; both classes work.
   748→2. **Token bridge** — paste RoyCSS's Tailwind config export (see `design-tokens.ts` `generateTailwindConfig()`) into `tailwind.config.js`.
   749→3. **Animation mapping** — Tailwind's `animate-pulse` → `roycss-anim-pulse-soft`; `animate-bounce` → `roycss-anim-bounce-in`.
   750→4. **Custom animations** — replace `tailwind.config.js` `keyframes` blocks with RoyCSS classes; remove the duplication.
   751→
   752→### 8.3 From Bootstrap
   753→
   754→Bootstrap's built-in animations are limited (`fade`, `show`). Migration:
   755→
   756→- `fade` → `roycss-anim-fade-in`
   757→- `show` (modal) → `roycss-anim-fade-in` + `roycss-page-scale-in`
   758→- Custom Bootstrap hover effects → `roycss-hover-*` equivalents
   759→- Spinner border/grow → `roycss-load-spinner` / `roycss-load-grow`
   760→
   761→Plus a token mapping from Bootstrap's SCSS variables to RoyCSS OKLCH custom properties.
   762→
   763→### 8.4 Version-to-Version
   764→
   765→Every minor release ships a migration guide. Example for 1.x → 2.x:
   766→
   767→- Renamed classes (`roycss-float` → `roycss-anim-float`).
   768→- Deprecated variants marked with a banner on the effect page.
   769→- Codemod `npx roycss migrate v2 ./src` performs all renames.
   770→- `replacementFor` metadata powers automatic redirects from old URLs.

   820→## 10. Performance Budget
   821→
   822→### 10.1 Per-Route Budgets
   823→
   824→| Route | JS (gz) | CSS (gz) | LCP | TTI | CLS |
   825→|-------|---------|----------|-----|-----|-----|
   826→| Landing | 80 kB | 14 kB | 1.0s | 1.2s | 0 |
   827→| Effect detail | 90 kB | 18 kB | 1.1s | 1.3s | 0 |
   828→| Explorer | 110 kB | 20 kB | 1.4s | 1.8s | 0 |
   829→| Search modal | +12 kB lazy | — | — | — | 0 |
   830→| Playground | +180 kB lazy | — | 1.8s | 2.2s | 0 |
   831→
   832→### 10.2 Strategies
   833→
   834→- **Route-level code splitting** — Playground, AI, and Explorer load on demand.
   835→- **Effect CSS lazy-loading** — only the visible effect's CSS is inlined; others load on hover (prefetch) or on click.
   836→- **Search index** — `search-index.json` (~120 kB gz) loads on idle; embeddings binary loads on first search open.
   837→- **Fonts** — Geist Sans/Mono via `next/font` with `display: swap`.
   838→- **Images** — only the logo and og:image; everything else is CSS-rendered.
   839→- **Preconnect** — to StackBlitz, CodeSandbox, GitHub for embed warmup.
   840→- **HTTP/3 + Brotli** — Caddyfile already configured for Brotli; add HTTP/3.
   841→- **Edge cache** — static assets cached 1 year; HTML cached 5 minutes.
   842→
   843→### 10.3 Render-Cost Transparency
   844→
   845→Every effect page surfaces render cost (see §3.2 Performance table). This metadata is computed at build time by:
   846→
   847→1. Parsing each effect's CSS via `lightningcss`.
   848→2. Detecting animated properties (`transform`, `opacity` → compositor; `box-shadow`, `color` → paint; `width`, `top` → layout).
   849→3. Estimating `bundleBytes` via `gzip` of the effect's CSS string.
   850→
   851→### 10.4 Monitoring
   852→
   853→- **Lighthouse CI** runs on every PR; budget regressions block merge.
   854→- **Real User Monitoring** via a privacy-preserving beacon (no cookies) — p75 LCP, p75 INP, p75 CLS reported to Grafana.
   855→- **Bundle analyzer** visualized at `/docs/internals/bundle` (public, for transparency).

   859→## 11. Accessibility
   860→
   861→### 11.1 Standards
   862→
   863→- **WCAG 2.1 AA** for all pages, including color contrast, focus visibility, and text resizing.
   864→- **WCAG 2.1 AAA** target for body text contrast (7:1) where the design permits.
   865→- **WAI-ARIA Authoring Practices** for all interactive widgets (search modal, tabs, explorers).
   866→- **Section 508** and **EN 301 549** compliance via the above.
   867→
   868→### 11.2 Per-Effect Accessibility Notes
   869→
   870→Every effect page documents:
   871→
   872→- `prefers-reduced-motion` behavior — what happens when the user opts out.
   873→- Flash safety — effects flashing >3 Hz are flagged "not photosensitive-safe".
   874→- Screen reader impact — whether the effect is decorative or affects semantics.
   875→- Keyboard operability — whether the effect interferes with focus rings.
   876→- Color contrast — whether the effect changes contrast on default surfaces.
   877→
   878→Effects that violate any rule carry a warning badge in the explorer and detail page.
   879→
   880→### 11.3 Site-Wide Accessibility Features
   881→
   882→- **Skip to content** link on every page (first focusable element).
   883→- **Focus ring** — always visible, OKLCH primary, 3px outline offset.
   884→- **Live region** — announces search result counts, copy confirmations, theme changes.
   885→- **Reduced motion site-wide** — when `prefers-reduced-motion: reduce`, all preview tiles render static; previews show a play button instead of auto-playing.
   886→- **High contrast mode** — `prefers-contrast: high` swaps tokens to maximize contrast.
   887→- **Screen reader testing** — automated via axe-core in CI; manual NVDA + VoiceOver + JAWS audits each release.
   888→- **Keyboard trap audit** — every modal, drawer, and dialog traps focus correctly and restores focus on close.
   889→
   890→### 11.4 Cognitive Accessibility
   891→
   892→- Plain-language summaries at the top of every concept page (≤ 8th-grade reading level).
   893→- Consistent navigation — same shell, same shortcuts, same patterns everywhere.
   894→- No surprise motion — previews play only on user interaction or hover, never on scroll-into-view (except explorer tiles, which pause when off-screen).
   895→- Predictable copy actions — every code block has the same action bar in the same order.

   936→- ✅ Public changelog entry merged.

   938→### 12.4 Risks & Mitigations
   939→
   940→| Risk | Likelihood | Mitigation |
   941→|------|-----------|------------|
   942→| Vector embeddings too heavy at runtime | Medium | Binary format + lazy load; fall back to lexical-only on slow devices |
   943→| Monaco editor bloats Playground bundle | High | Load Monaco from CDN; ship a CodeMirror fallback for low-end devices |
   944→| AI generation cost | Medium | Aggressive caching of common prompts; rate-limit anonymous tier |
   945→| Version sprawl (10+ versions) | Low | Hard cap supported versions to latest 3; older versions are read-only |
   946→| Effect preview flicker on theme switch | Medium | All previews use CSS custom properties; theme switch is one class swap |

   950→## Appendix A: Tech Stack
   951→
   952→- **Framework:** Next.js (App Router, RSC) on Node 20+
   953→- **Styling:** Native CSS + `@layer`, RoyCSS tokens, no CSS-in-JS
   954→- **Search:** MiniSearch (lexical) + Transformers.js MiniLM (vector)
   955→- **Editor:** Monaco (CDN) with CodeMirror fallback
   956→- **Markdown:** MDX with remark/rehype plugins
   957→- **Icons:** Lucide (tree-shaken)
   958→- **Hosting:** Caddy (HTTP/3, Brotli) + Cloudflare CDN
   959→- **CI:** GitHub Actions (lint → test → build → Lighthouse → deploy)
   960→- **Analytics:** Plausible (privacy-preserving, no cookies)
