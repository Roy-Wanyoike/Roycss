Currently every effect card has a single "Copy" button that copies CSS. Replace it with a dropdown offering multiple output formats.

1. **CSS Class** — the current behavior (`.roycss-pulse-glow { ... }`)

6. **Vue SFC** — `<style scoped> ... </style>` block

1. Create a `CopyDropdown` component that replaces the existing "Copy" button

4. On selection: copy to clipboard + show brief "Copied as [format]!" toast
5. Remember user's last chosen format in `localStorage` — pre-select it next time

**Responsive**:
- Desktop: dropdown opens below/beside the button
- Mobile: dropdown becomes a bottom sheet or full-width menu

**Accessibility**:
