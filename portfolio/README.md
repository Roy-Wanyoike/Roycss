# Royford Wanyoike Wamaitha — Portfolio

Personal portfolio website for Royford Wanyoike Wamaitha, Software Engineer and Quickbase Solutions Engineer.

## Development

```bash
cd portfolio
npm install
npm run dev
```

Runs on port 3001.

## Structure

- `src/components/portfolio/` — Portfolio UI components (hero, about, projects, etc.)
- `src/lib/portfolio-data.ts` — Portfolio content data
- `src/app/api/contact/` — Contact form API route
- `public/images/` — Profile photos and project images
