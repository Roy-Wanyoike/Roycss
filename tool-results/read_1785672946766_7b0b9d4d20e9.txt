  3600→  * `findTopLevelBlocks` — brace-matching walker returning `{ selector, body, isAtRule }`. String-aware (so `content: "}"` doesn't confuse it). Top-level `;` (e.g. end of `@import url("...");`) advances the selector start.

  3602→  * `extractOwnDeclarations` — pulls `property: value` pairs at depth 0 within a block body, so CSS Nesting child-rules are skipped (they get walked as their own blocks). Handles trailing declaration without `;`, skips braces, honours quoted strings.
  3603→  * `normalizeScope` — trims and collapses whitespace in the enclosing block's selector for use as the variable's scope.
  3604→  * `findVarReferences` — scans for `\bvar\s*\(`, matches parens to find the closing `)`, splits inner on the FIRST top-level comma (depth 0 within the var), then RECURSES into the fallback so `var(--a, var(--b, #000))` yields both `--a` (with fallback `var(--b, #000)`) and `--b` (with fallback `#000`).   3605→- Implemented **graph analysis layer**:
  3606→  * `tarjanSCC` — iterative Tarjan strongly-connected-components algorithm (no recursion → no stack-overflow on large graphs). Returns SCCs as string arrays.
  3607→  * `findCyclePath` — given an SCC, walks edges WITHIN the SCC from any start node, tracking visited nodes; when a visited node is reached, returns the slice from its first occurrence plus the revisit (e.g. `["--a", "--b", "--a"]`). Self-loop SCCs (size 1 with `adj(n).has(n)`) yield `["--a", "--a"]`.
  3608→  * `computeLayers` — longest-path layering via Kahn's algorithm (iterative). Builds a DAG restricted to non-cycle nodes (edges from cycle nodes are ignored so non-cycle consumers of cycle nodes still get a layer), computes in-degree, processes leaves-first, and assigns `layer(t) = max(layer(t), layer(n) + 1)` as each dep is processed. Cycle nodes are excluded — they go to the bottom "Cycles" zone.
  3609→  * `substituteVars` — recursively substitutes `var(--x)` references in a value, stopping at cycles (uses fallback, else `<cycle>`) and undefined targets (uses fallback, else `<undef: --x>`). Depth-capped at 50.
  3610→  * `isColorValue` / `extractSwatch` — detects oklch/oklab/lab/lch/hwb/rgb/hsl/#hex/color-mix/color()/named-colors and rejects values containing unresolved `var()`.
